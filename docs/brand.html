01

From brief to better UI.

An example workflow, not an automatic pipeline. Ask naturally, or choose the pass your project needs.

  1. Set contextinit captures product context in PRODUCT.md. document derives DESIGN.md from existing code.
  2. Shape the workshape plans the UX and UI before implementation.
  3. Evaluatecritique reviews UX. audit checks accessibility, performance, and responsive behavior.
  4. RefineChoose focused passes such as polish, adapt, or optimize, then verify the result.
